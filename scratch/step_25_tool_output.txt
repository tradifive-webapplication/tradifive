To open your web user application and connect your social media account, follow these steps:

### 1. Start the Web User App in the Terminal
Open your terminal (PowerShell, Command Prompt, or the VS Code terminal) in the project's root folder (`c:\Users\nikil\Downloads\fialgo-connect-main\fialgo-connect-main`) and run the following command:

```bash
npm run dev
```

> [!NOTE]
> If you are using **Bun** as your package manager (as there is a `bun.lockb` file in the project), you can also run:
> ```bash
> bun run dev
> ```

### 2. Access the Application
Once the command is running, the terminal will show a local address. By default, it will be:
* **URL:** `http://localhost:5173`

Hold `Ctrl` and click the link in your terminal, or open your web browser and go to `http://localhost:5173`.

---

### 3. Connect Your Instagram Account
Once the app is running in your browser:
1. **Log in** to your account.
2. Navigate to the **Settings** page from the sidebar menu (or go directly to `http://localhost:5173/settings`).
3. Under the default **Profile** tab, scroll down to the **Contact & Social** card.
4. Look for the **Instagram Handle** input field.
5. Enter your Instagram handle (e.g., `@your_username`).
6. Click **Sync Command Identity** at the bottom of the page to save your social media info.
